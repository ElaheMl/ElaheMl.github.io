# ElaheMl Portfolio

Personal portfolio website showcasing professional background, projects, skills, experience, and selected work.

## Live Website

**[Visit Portfolio](https://elaheml.github.io/)**

## Features

- Modern responsive portfolio design
- Professional Hero section
- About Me section
- Skills and expertise
- Project showcase
- Contact section
- Optimized for slow / restricted networks (self-hosted assets, WebP images, service worker caching)
- Responsive layout for desktop, tablet, and mobile
- Interactive UI elements and animations

## Technologies

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- Git & GitHub
- GitHub Pages
